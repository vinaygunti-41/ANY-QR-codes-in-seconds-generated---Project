## 📖 About

**QR Studio Pro** lets anyone generate high-resolution, customizable QR codes — including ones with a transparent background — and scan existing QR codes using a camera or an uploaded image. Everything runs **entirely in the browser**: nothing is uploaded, stored on a server, or tracked.

The interface uses a **dark, glassmorphic, neon-gradient design** with floating particles, smooth animations, and full mobile responsiveness.

## ✨ Features

| Feature | Description |
|---|---|
| 🎨 **QR Generator** | Instantly turn any link or text into a QR code |
| 🫥 **Transparent Background** | Export QR codes with a see-through background |
| 📷 **Built-in Scanner** | Scan via camera or by uploading an image |
| ⬇️ **One-click Download** | Save a crisp PNG with a single click |
| 📋 **Copy & Share** | Copy the QR image to clipboard or use native share |

| 📱 **Fully Responsive** | Looks great on desktop, tablet, and mobile |
| 🔒 **100% Private** | No tracking, no ads, no data ever leaves your device |

##  Getting Started

No build tools, frameworks, or installation required.

### Option 1 — Just open it
1. Download or clone this repository.
2. Open `qr-studio-pro.html` directly in any modern browser.

### Option 2 — Clone with Git
```bash
git clone https://github.com/vinaygunti-41/ANY-QR-codes-in-seconds-generated---Project.git
cd ANY-QR-codes-in-seconds-generated---Project
```
Then open `qr-studio-pro.html` in your browser.

### Option 3 — Host it for free with GitHub Pages
1. Go to your repository's **Settings → Pages**.
2. Under **Branch**, select `main` and `/ (root)`.
3. Save — your site will be live at `https://<username>.github.io/<repo-name>/` within a minute.

##  Tech Stack

- **HTML5** — semantic structure
- **CSS3** — glassmorphism, gradients, animations, responsive layout
- **Vanilla JavaScript** — no frameworks, no build step
- [**qrcodejs**](https://github.com/davidshimjs/qrcodejs) — QR code generation
- [**html5-qrcode**](https://github.com/mebjas/html5-qrcode) — camera & image-based QR scanning
- **Google Fonts** — Space Grotesk & Inter
